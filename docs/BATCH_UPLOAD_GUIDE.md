# 문제 일괄 업로드 가이드

## 개요

Excel 또는 CSV 파일을 사용하여 문제를 일괄로 업로드할 수 있습니다.

## 템플릿 다운로드

관리자 페이지의 "일괄 업로드" 탭에서 "템플릿 다운로드" 버튼을 클릭하여 템플릿 파일을 다운로드할 수 있습니다.

## 파일 형식

### 지원 형식
- CSV 파일 (`.csv`)
- Excel 파일 (`.xlsx`, `.xls`)

### 컬럼 구조

| 컬럼명 | 필수 | 설명 | 예시 |
|--------|------|------|------|
| 자격증 | ✅ | 자격증 유형 | 정보처리기사, 컴퓨터활용능력, 빅데이터분석기사, 경영정보시각화능력, ADsP, SQLD |
| 카테고리 | ✅ | 카테고리 (대분류-중분류-소분류-세분류-세세분류) | 1-2-3-4-5 |
| 문제제시문 | ✅ | 문제 본문 | 다음 중 관계형 데이터베이스의 특징이 아닌 것은? |
| 서브제시문 | ❌ | 서브 제시문 (선택사항) | (빈 값 가능) |
| 선택지1 | ✅ | 첫 번째 선택지 | 데이터 중복 최소화 |
| 선택지2 | ✅ | 두 번째 선택지 | ACID 속성 보장 |
| 선택지3 | ✅ | 세 번째 선택지 | 정규화 지원 |
| 선택지4 | ✅ | 네 번째 선택지 | 계층형 구조 |
| 선택지5 | ❌ | 다섯 번째 선택지 (4지선다인 경우 생략 가능) | 트랜잭션 처리 |
| 정답 | ✅ | 정답 (A, B, C, D, E) | D |
| 해설 | ✅ | 문제 해설 | 관계형 데이터베이스는 계층형 구조가 아닌 테이블 기반 구조를 사용합니다. |
| 난이도 | ✅ | 난이도 (상, 중, 하) | 중 |
| 태그 | ❌ | 태그 (쉼표로 구분) | 데이터베이스,기초 |
| 기출회차 | ❌ | 기출회차 (YYYY-MM 형식) | 2024-01 |
| 기출번호 | ❌ | 기출번호 (숫자) | 01 |
| 출제빈도 | ❌ | 출제빈도 (숫자) | 5 |
| 이미지URL | ❌ | 서브제시문 이미지 URL | https://example.com/image.jpg |

## 입력 예시

```csv
자격증,카테고리,문제제시문,서브제시문,선택지1,선택지2,선택지3,선택지4,선택지5,정답,해설,난이도,태그,기출회차,기출번호,출제빈도,이미지URL
정보처리기사,1-2-3,다음 중 관계형 데이터베이스의 특징이 아닌 것은?,"",데이터 중복 최소화,ACID 속성 보장,정규화 지원,계층형 구조,트랜잭션 처리,D,관계형 데이터베이스는 계층형 구조가 아닌 테이블 기반 구조를 사용합니다.,중,"데이터베이스,기초",2024-01,01,5,
```

## 주의사항

### 필수 항목
- 자격증, 카테고리, 문제제시문, 선택지(최소 4개), 정답, 해설, 난이도는 필수입니다.

### 정답 형식
- 정답은 반드시 **A, B, C, D, E** 중 하나여야 합니다.
- 정답 인덱스는 선택지 개수를 초과할 수 없습니다.
  - 예: 선택지가 4개인 경우 정답은 A, B, C, D만 가능

### 난이도 형식
- 난이도는 반드시 **상, 중, 하** 중 하나여야 합니다.

### 카테고리 형식
- 카테고리는 숫자와 하이픈(-)으로 구성되어야 합니다.
- 예: `1-2-3-4-5`, `1-2-3`

### 기출회차 형식
- 기출회차는 **YYYY-MM** 형식이어야 합니다.
- 예: `2024-01`, `2023-03`

### 태그 형식
- 태그는 쉼표(,)로 구분합니다.
- 예: `데이터베이스,기초,정규화`

### 선택지 개수
- 최소 4개의 선택지가 필요합니다.
- 5지선다인 경우 선택지5 컬럼에 값을 입력합니다.
- 4지선다인 경우 선택지5 컬럼은 비워둡니다.

## 업로드 프로세스

1. **템플릿 다운로드**: 템플릿 파일을 다운로드합니다.
2. **데이터 입력**: Excel 또는 Google Sheets에서 템플릿에 맞춰 문제 데이터를 입력합니다.
3. **파일 저장**: CSV 형식으로 저장합니다 (Excel의 경우 "다른 이름으로 저장" → "CSV UTF-8(쉼표로 구분)" 선택).
4. **파일 선택**: 관리자 페이지에서 파일을 선택합니다.
5. **미리보기 확인**: 파일 선택 후 미리보기에서 유효한 문제 수와 오류/경고를 확인합니다.
6. **업로드 시작**: "업로드 시작" 버튼을 클릭합니다.
7. **결과 확인**: 업로드 완료 후 성공/실패 결과를 확인합니다.

## 오류 처리

### 파싱 오류
- 파일 형식이 올바르지 않거나 필수 필드가 누락된 경우 파싱 오류가 발생합니다.
- 오류가 있는 행은 업로드되지 않으며, 오류 목록에 표시됩니다.

### 저장 오류
- 데이터베이스 제약 조건 위반 또는 권한 문제로 저장에 실패할 수 있습니다.
- 실패한 문제는 오류 목록에 표시되며, 문제 내용과 오류 메시지를 확인할 수 있습니다.

## Google Sheets 사용 시

1. Google Sheets에서 템플릿을 열고 데이터를 입력합니다.
2. 파일 → 다운로드 → 쉼표로 구분된 값(.csv) 선택
3. 다운로드된 CSV 파일을 업로드합니다.

## Excel 사용 시 주의사항

- Excel에서 CSV로 저장할 때 한글이 깨질 수 있습니다.
- 해결 방법: "다른 이름으로 저장" → "CSV UTF-8(쉼표로 구분)" 선택
- 또는 템플릿 다운로드 버튼을 사용하여 UTF-8 BOM이 포함된 CSV 파일을 다운로드하세요.

## 성능 고려사항

- 대량 업로드 시 배치 처리로 진행됩니다 (10개씩).
- 업로드 진행률이 실시간으로 표시됩니다.
- 네트워크 상태에 따라 업로드 시간이 달라질 수 있습니다.

## 제한사항

- 현재 이미지 파일은 직접 업로드할 수 없습니다.
- 이미지가 필요한 경우:
  1. 이미지를 Supabase Storage에 먼저 업로드
  2. 이미지 URL을 "이미지URL" 컬럼에 입력
  3. 일괄 업로드 실행
