프로젝트 기획안: HabitQuest (해빗퀘스트)

1. 프로젝트 개요

프로젝트명: HabitQuest (해빗퀘스트)

한 줄 설명: 매일의 습관을 완료하면 경험치를 얻고 캐릭터를 성장시키는 게이미피케이션 습관 추적기

타겟 사용자: * 새해 목표나 습관 형성에 매번 실패하는 2030 세대

단순한 체크리스트보다 시각적인 보상과 재미를 추구하는 사용자

해결하려는 문제: * 단조로운 습관 관리 앱은 동기 부여가 지속되지 않음 (작심삼일)

성취감을 즉각적으로 느끼기 어려워 중도 포기율이 높음

2. 사용자 스토리

**[사용자]**로서, 나는 **[동기 부여]**를 위해 **[습관을 완료할 때마다 캐릭터가 성장하는 모습]**을 보고 싶다.

**[사용자]**로서, 나는 **[꾸준한 기록]**을 위해 **[오늘 해야 할 습관 목록을 한눈에 확인하고 쉽게 체크]**하고 싶다.

**[사용자]**로서, 나는 **[나의 성취]**를 확인하기 위해 **[지난주 달성률과 연속 달성일(Streak) 통계]**를 보고 싶다.

**[사용자]**로서, 나는 **[목표 설정]**을 위해 **[새로운 습관을 등록하고 난이도(보상 수준)를 설정]**하고 싶다.

3. 화면 설계

[화면 1: 홈 (대시보드)]

목적: 사용자의 현재 캐릭터 상태 확인 및 오늘의 할 일 수행

화면 구성:

상단: * 현재 레벨, 경험치 바(Progress Bar)

캐릭터 애니메이션 (대기/성공 모션)

연속 달성일(Streak) 불꽃 아이콘 표기

중간: * 오늘 날짜 표시

'오늘의 퀘스트' 리스트 (습관 목록)

각 리스트 우측에 완료 체크박스 (클릭 시 경험치 획득 효과)

하단: * 플로팅 버튼 (+) : 새 습관 추가 모달 호출

하단 탭바 (홈 / 통계 / 설정)

[화면 2: 통계 (리포트)]

목적: 과거 기록 열람 및 성취감 고취

화면 구성:

상단: * 이번 주 전체 달성률 (%)

'이번 달 획득한 경험치' 요약

중간: * 주간 히트맵 (Github 잔디 심기 스타일) - 완료 빈도에 따라 색상 진하기 변화

베스트 습관 (가장 잘 지킨 습관) 랭킹 표시

하단: * 획득한 배지 목록 (예: 7일 연속 달성, 레벨 10 달성 등)

4. 기술 요구사항

웹앱: React (v18), Vite

언어: TypeScript

상태 관리: React Context API 또는 Zustand

서버 및 DB: Supabase (Auth, Database, Realtime)

디자인: * UI 프레임워크: Shadcn/UI (Radix UI 기반)

스타일링: Tailwind CSS

아이콘: Lucide-react

(선택) 별도 다른 기술: * 애니메이션: Framer Motion (캐릭터 움직임 및 경험치 바 효과)

차트: Recharts (통계 화면 그래프 구현)
