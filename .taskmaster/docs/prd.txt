프로젝트 기획안: 성인 자격증시험 기출문제 개인화 서비스(Certiq)

1. 프로젝트 개요

프로젝트명: Certiq (자격증큐레이터터)

한 줄 설명: 최초 진단문제 10문을 풀고나면 정오데이터를 분석한 후 취약 부분에 대한 문제 위주로 추천해서 학습하고 오답노트도 생성하는 초개인화 학습 앱

타겟 사용자: 자격증 시험을 준비하는 모든 수험생

해결하려는 문제: 
- 아는 문제는 덜고 모르는 문제 위주로 집중공략하여 학습 시간과 학습 비용을 줄이고고 효율적인 수험 준비를 하게 함
- 매일 본인이 정해놓은 문제수를 배달받아서 짜투리 시간에 문제를 풀고, 틀린 문제는 복습하고 해서 매일 조금씩 반복 학습하면서 본인의 취약점을 보완 하게 함 
- 매일 조금씩 반복을 통해 자기 주도 학습습관을 만들고, 합격의 경험을 통해 다른 자격증 취득에도 도전할 수 있도록 연계계 

2. 사용자 스토리

[사용자]로서, 나는 [학습시간과 학습에 드는 비용]을 줄이기 위해 [내가 알고 있는 문제는 최소화 하고 모르는 문제 위주로 학습]하기를 원한다.

[사용자]로서, 나는 [나의 학습성취도]를 확인하기 위해 [매일 문제풀이 달성률과 연속 달성일(Streak) 통계]를 [학습 현황 대시보드]에서 확인하기를 원한다다

[사용자]로서, 나는 [내가 설정한 학습목표]를 달성하면 [보상을] 받기를 원한다.

[사용자]로서, 나는 [어려운 개념]을 [쉽게 이해하기 위해 AI 튜터의 설명]을  바로 받고 싶다.


3. 핵심 기능

3.1. 초기 진단 시스템
- 목표: 사용자의 현재 수준 파악 및 초기 데이터 수집(아주 중요)
- 기능:
  - 자격증 선택 :최초 자격증 선택 목록은 '정보처리기사(필기), 컴퓨터활용능력(필기), 빅데이터분석기사(필기), 경영정보시각화능력(필기), ADsP(필기기), SQLD(필기) 총 6개'
  - 미니 진단 테스트 (10문제 필수)
  - 진단 결과 리포트 (레이더 차트 그래프)
  - 취약 영역 분석 및 시각화
  - 맞춤형 학습 전략 제시

3.2. 개인화 학습 추천 시스템
- 목표: 취약 부분 문제 위주로 추천하여 효율적 학습
- 기능:
  - 사용자 취약 영역 기반 문제 추천 알고리즘
  - 일일 학습 문제 세트 생성
    - 자격증별 일일 문제 수 설정 (1문제, 3문제, 5문제 중 선택)
    - 프로필 > 학습설정에서 자격증별로 개별 설정 가능
    - 설정한 문제 수만큼 매일 "오늘의 문제"에 표시
    - 기존 세트의 문제 수가 설정과 다를 경우 자동 재생성
  - 학습 진행률 추적
    - 오늘 완료한 고유 문제 수 / 전체 문제 수로 계산
    - 중복 제거 로직 적용 (같은 문제를 여러 번 풀어도 1회로 카운트)
  - 약점 분석 및 프로그레스 표시
  - 기출문제 풀이 기능
    - 자격증 선택 (드롭다운)
    - 기출년도 선택 (드롭다운, DB에서 실제 존재하는 연도만 표시)
    - 기출회차 선택 (드롭다운, 선택한 연도에 맞는 회차만 표시)
    - 기출과목 선택 (드롭다운, 1과목~5과목, 전체)
    - 선택한 조건에 맞는 문제를 기출번호 오름차순으로 정렬하여 표시

3.3. 마이크로 러닝 문제 풀이
- 목표: 방해 요소 없는 몰입 환경에서의 문제 풀이
- 기능:
  - 카드 형태의 문제 표시 (스와이프 방식)
  - 5지 선다형 답안 기본 : 과정에 따라 4지 선다형 답안도 있으나 이건 추후 개발에 반영 예정 
  - 채점은 문제를 다 풀고 나면 '문제-정답-수험생답-해설'형식으로 제시, 그리고 문제 푼 시간도 표시
  - 진행률 표시줄

3.4. AI 튜터 시스템
- 목표: 모르는 내용을 즉시 해결하고 이탈 방지
- 기능:
  - 해설 카드 (Bottom Sheet)
  - 전문적인 원본 해설 텍스트 표시
  - AI 하이라이트: 어려운 용어에 점선 밑줄 표시
  - 밑줄 터치 시 AI 튜터 팝업
  - 쉬운 비유를 통한 개념 설명
  - 피드백 버튼 (이해됐어요 / 더 쉽게 설명해줘)
  - AI 선생님 캐릭터 아이콘

3.5. 스마트 오답 노트
- 목표: 에빙하우스 망각 곡선에 따른 효율적 복습
- 기능:
  - 오답 문제 자동 수집
  - 탭 구분: 오늘의 오답 / 복습 알림(N개) / 졸업한 문제
  - 망각 예정일 계산 및 알림 (예: "3일 뒤 망각 예정")
  - 복습 알림 문제만 모아 풀기 기능
  - 문제 요약 한 줄 표시

3.6. 대시보드 및 통계
- 목표: 학습 현황 한눈에 파악
- 기능:
  - 환영 메시지: 사용자명과 선택한 과정명, 일일 문제 수 표시
  - 연속 학습일(Streak) 표시 (불꽃 아이콘)
  - 오늘의 문제 카드
    - 자격증별 설정된 일일 문제 수만큼 문제 배달
    - "주문하신 {문제수}문제가 배달되었어요~" 메시지
  - 기출문제 카드
    - 자격증, 기출년도, 기출회차, 기출과목 선택
    - 선택한 조건에 맞는 기출문제 풀기
  - 학습 캘린더: 연속 학습일 및 학습 진행 상황 시각화
  - 약점 분석 프로그레스 바
  - 학습 성취도 통계

4. 화면 설계

4.1. 온보딩 화면 (첫 진입 & 콜드 스타트)
- 목표 설정 화면
  - 타이틀: "어떤 자격증을 준비하시나요?"
  - 자격증 선택 버튼 (정보처리기사(필기), 컴퓨터활용능력(필기), 빅데이터분석기사(필기), 경영정보시각화능력(필기), ADsP(필기기), SQLD(필기))
  - 목표 시험일 설정 (캘린더 피커)
- 미니 진단 테스트 (필수)
  - 타이틀: "딱 10문제로 합격 가능성을 진단해드려요."
  - 화면 중앙에 문제 카드 1개씩 노출 (스와이프 방식) 
  - 답안 선택 시 바로 다음 문제로 넘어가는 빠른 인터랙션
  - 5문제 풀고나면 '힘내세요. 다왔어요' 라는 응원멘트 알림림
- 진단 결과 리포트
  - 레이더 차트 그래프 ("{회원}님의 '데이터베이스' 영역은 상위 10%지만, '운영체제'는 보완이 필요해요!")
  - CTA 버튼: [맞춤형 문제제 시작하기]

4.2. 홈 화면 (메인 대시보드)
- 목적: 고민 없이 바로 학습 시작
- 상단 영역 (Top Bar)
  - 홈 링크 (좌측)
  - 마이페이지 링크 (우측)
  - 관리자 링크 (관리자 계정만 표시)
- 환영 메시지
  - "{사용자명}님 {과정명} 과정 매일 {문제수}문제 배달 선택하셨어요~" 형식
  - 선택한 과정명과 문제수는 파란색 강조 표시
- 히어로 영역 (Main)
  - 오늘의 문제 카드
    - 자격증별 일일 문제 수 설정 (1문제, 3문제, 5문제 중 선택)
    - "주문하신 {문제수}문제가 배달되었어요~" 메시지
    - [학습 시작하기] 버튼
  - 기출문제 카드
    - 자격증 선택 (드롭다운, 6개 자격증)
    - 기출년도 선택 (드롭다운, DB에서 실제 존재하는 연도만 표시)
    - 기출회차 선택 (드롭다운, 선택한 연도에 맞는 회차만 표시)
    - 기출과목 선택 (드롭다운, 1과목, 2과목, 3과목, 4과목, 5과목, 전체)
    - 선택한 조건에 맞는 문제를 기출번호 오름차순으로 정렬하여 표시
    - [기출문제 풀기] 버튼
- 학습 캘린더
  - 연속 학습일(Streak) 표시
  - 학습 진행 상황 시각화

4.3. 문제 풀이 화면 (핵심 기능 1: 마이크로 러닝)
- 목적: 방해 요소 없는 몰입 환경
- 상단: 진행률 표시줄 (예: 1/5)
- 중앙:
  - 깔끔한 텍스트의 문제 지문
  - 5지 선다형 버튼 (터치 영역 넓게)
  - 선택지 번호: ①②③④⑤ 형식
- 인터랙션:
  - 답안 선택 후 "다음" 버튼 클릭하여 다음 문제로 이동
  - 마지막 문제까지 풀면 "학습 완료" 버튼 표시
  - 모든 문제를 풀면 결과 화면으로 이동
- 결과 화면:
  - 각 문제별 상세 결과 표시
  - 형식: "문제1. 틀림", "정답: ①", "선택: ②", "해설: (해설내용)", "소요시간: 2초"
  - 모든 정보 좌측 정렬
  - 정답과 선택 표시는 배경색 없이 숫자만 표시
  
4.5. 오답 노트 화면 (스마트 리뷰)
- 목적: 에빙하우스 망각 곡선에 따른 효율적 복습
- 탭 구분: [오늘의 오답] / [복습 알림(N개)] / [졸업한 문제]
- 리스트 아이템:
  - 문제 요약 한 줄
  - 뱃지: "3일 뒤 망각 예정" (D-3 경고 아이콘)
- UI 요소:
  - [복습 알림 문제만 모아 풀기] 플로팅 버튼

4.6. 문제입력관련자 화면 (관리자)
- 좌측 사이드바 네비게이션
  - 문제 입력
  - 문제 목록
- 과정선택 : 정보처리기사(필기), 컴퓨터활용능력(필기), 빅데이터분석기사(필기), 경영정보시각화능력(필기), ADsP(필기), SQLD(필기)
- 문제입력 화면
  - 문제 제시문 입력란 (필수)
  - 문제 서브 제시문 입력란 (선택): 이미지 업로드 지원 (Supabase Storage)
  - 카테고리 입력란: 5단계 분류 (과정분류-과목분류-주요항목-세부항목-세세항목)
    - 각 단계별 숫자 입력
    - 자동으로 레이블 생성 (예: 1-2-3-4-5)
  - 선택지 입력란: 5지선다(default), 4지선다 옵션
    - 선택지 번호: ①②③④⑤ 형식
  - 정답 선택: ①②③④⑤ 중 선택
  - 해설 입력란 (필수)
  - 난이도 선택: 상-중-하 옵션 (추후 사용자 정오데이터 기반 자동 분류 예정)
  - 출제빈도 입력란 (선택)
  - 기출년도 (선택): YYYY 형식 (예: 2024) - 드롭다운으로 입력
  - 기출회차 (선택): 숫자 형식 (예: 1, 2) - 드롭다운으로 입력
  - 기출번호 (선택): 2자리 숫자 형식 (예: 01, 15)
- 문제 목록 화면
  - 문제 검색 및 필터링 (자격증 유형, 카테고리, 검색어)
  - 기출회차별 필터링 및 기출번호 오름차순 정렬
  - 문제 수정 및 삭제 기능
  - 페이지네이션 지원

5. 기술 요구사항

5.1. Frontend
- Framework: React (v18+)
- Build Tool: Vite (빠른 빌드 속도 및 HMR 지원)
- Language: TypeScript (엄격한 타입 지정을 통한 유지보수성 확보)
- UI/UX Design System: Shadcn UI (Tailwind CSS 기반의 재사용 가능한 컴포넌트)
- 아이콘: Lucide-react
- 애니메이션: Framer Motion (캐릭터 움직임 및 경험치 바 효과)
- 차트: Recharts (통계 화면 그래프 구현)

5.2. Backend & Infrastructure
- Backend & DB: Supabase (BaaS)
- Auth: 사용자 인증 (Email, Social Login)
- Database: PostgreSQL (학습 데이터 및 문제 은행)
- Storage: 이미지 저장 (OCR 촬영 이미지, 프로필)
- Edge Functions: AI API 및 OCR API 호출을 위한 백엔드 로직 (API Key 은닉)

5.3. 데이터베이스 스키마 요구사항
- 사용자 테이블 (users)
  - 기본 정보 (이름, 이메일, 프로필 이미지)
  - 자격증 선택 정보
  - 목표 시험일
  - 연속 학습일(Streak)
  - 일일 문제 수 설정 (daily_question_count): JSONB 형식으로 자격증별 문제 수 저장
    - 예: {"빅데이터분석기사": 3, "ADsP": 5}
  - 관리자 여부 (is_admin): 관리자 권한 확인용
- 문제 테이블 (questions)
  - 문제 ID, 지문, 선택지, 정답, 해설
  - 자격증 유형, 카테고리, 난이도
  - 태그 (영역별 분류)
  - 서브 제시문 (sub_content): 선택사항
  - 서브 제시문 이미지 URL (sub_content_image_url): Supabase Storage URL
  - 출제빈도 (frequency): 선택사항
  - 기출회차 (exam_session): YYYY-MM 형식 (예: 2024-01)
  - 기출번호 (exam_number): 해당 회차 내 문제 번호 (2자리 숫자)
- 진단 결과 테이블 (diagnosis_results)
  - 사용자 ID, 진단 일시
  - 영역별 점수 (JSON)
  - 취약 영역 분석 결과
- 학습 기록 테이블 (study_records)
  - 사용자 ID, 문제 ID, 풀이 일시
  - 정답 여부, 소요 시간
  - 사용자 답안
- 오답 노트 테이블 (wrong_answers)
  - 사용자 ID, 문제 ID
  - 오답 횟수, 마지막 오답 일시
  - 복습 예정일 (에빙하우스 망각 곡선 기반)
  - 졸업 여부
- 일일 학습 세트 테이블 (daily_sets)
  - 사용자 ID, 생성 일시
  - 문제 ID 목록 (JSON)
  - 완료 여부, 완료 일시

5.4. API 요구사항
- Supabase Edge Functions:
  - AI 튜터 API 호출 (용어 설명 생성)
  - OCR API 호출 (이미지 텍스트 인식)
  - 문제 매칭 알고리즘
  - 유사 문제 생성 (AI)
- Supabase Realtime:
  - 학습 진행률 실시간 업데이트
  - 알림 실시간 전송

6. 구현 우선순위

Phase 1 (MVP - 핵심 기능):
- 사용자 인증 및 온보딩
- 초기 진단 시스템 (10문제)
- 기본 문제 풀이 화면
- 오답 노트 기본 기능
- 홈 대시보드

Phase 2 (관리자 화면) - 완료
- 문제입력 화면
  - 문제 입력 폼 (QuestionInputForm)
  - 카테고리 5단계 분류 시스템 (과정분류-과목분류-주요항목-세부항목-세세항목)
  - 이미지 업로드 기능 (Supabase Storage)
  - 기출년도, 기출회차, 기출번호 필드
  - 자동 폼 초기화 기능 (저장 후)
- 문제 목록 및 수정 화면
  - 문제 목록 조회 (검색, 필터링, 페이지네이션)
  - 문제 수정 기능
  - 문제 삭제 기능
  - 기출회차별 필터링 및 정렬
  - 수정 후 문제 목록으로 자동 이동

Phase 2.5 (사용자 기능 개선) - 완료
- 프로필 페이지 개선
  - 좌측 사이드바 네비게이션 (회원정보수정, 학습설정, 알림설정)
  - 학습설정: 자격증별 일일 문제 수 설정 (1, 3, 5문제)
  - JSONB 형식으로 자격증별 문제 수 저장
- 대시보드 개선
  - 환영 메시지: 사용자명과 선택한 과정명, 일일 문제 수 표시
  - 오늘의 문제 카드: 설정된 문제 수 정확히 반영
  - 기출문제 카드: 연도/회차/과목 드롭다운 선택 기능
- 학습 화면 개선
  - 결과 화면 레이아웃 개선 (문제-정답-선택-해설-소요시간)
  - 선택지 번호 ①②③④⑤ 형식 적용
  - 진행률 계산 로직 개선 (중복 제거)

Phase 3 (개인화):
- 개인화 학습 추천 알고리즘
- 상세 통계 및 분석

Phase 4 (고급 기능):
- 에빙하우스 망각 곡선 기반 복습 알림


7. 성공 지표
